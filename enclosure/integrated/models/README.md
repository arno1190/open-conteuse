# Manufacturer model provenance

These assembly-reference STL meshes are derived from Adafruit's published STEP files in [Adafruit_CAD_Parts](https://github.com/adafruit/Adafruit_CAD_Parts). Copyright2016 Adafruit Industries; MIT licence reproduced in `LICENSE.adafruit`.

`hardware/integration/catalog.json` records the original source URL, verified Git blob identity, STEP SHA256, normalized source bounding box and derived STL SHA256 for each mesh. Normalization translates the source bounding-box minimum to the origin; geometry is not resized to match catalogue prose. CadQuery2.8 STEP import and STL export (linear tolerance0.06mm, angular tolerance0.15rad, binary output) were used. `scripts/fetch_integration_models.py` verifies/caches the original STEP files and can rebuild reference meshes in the work directory without silently changing frozen hashes. Manufacturer shapes can omit detail; notably the slide switch model is only a body envelope. Battery CAD and retail dimensions differ, so the placement checker uses a conservative larger envelope.

MCU and regulator are labelled dimensional reservations, not fabricated manufacturer meshes. Controls and mute-latch visual solids are simplified references; native KiCad is authoritative for their circuitry. Never print these purchased-component meshes as enclosure parts. Printable prototype geometry is in `../print`, generated by `../integrated.scad`.
