# Compact comparison envelopes

`targets.scad` shows the existing case, approximate advertised Miyoo reference sizes and the proposed custom sizes at true relative scale. It is generated by `scripts/compact_assessment.py` from `hardware/compact/assessment.json`.

These are solid comparison envelopes. They contain no component placement, routing, mounting, connector openings, acoustic chamber, battery retention or print release. Do not scale the previous shell or use these solids as a fabricated enclosure.

See [compact hardware assessment](../../docs/research/COMPACT_HARDWARE.md) and [same-scale PNG](../../docs/research/compact-size-comparison.png). All dimensions use width × height × depth in millimetres. Physical validation remains pending.
